## Цель

Подтвердить осуществимость conversation agent-маршрутизатора на HA 2026.11.1 с пользовательским llamacpp conversation agent до реализации морфологии.

## Работа

- [ ] Проверить исходники именно тега HA `2026.11.1`: conversation entity, подготовку локальных интентов, результат отсутствия совпадения и делегирование агенту.
- [ ] Зафиксировать репозиторий, установленную версию и entity ID llamacpp-интеграции.
- [ ] Проверить правила штатного `prefer_local_intents`, включая фильтрацию для агентов с `CONTROL`; определить эквивалентную политику маршрутизатора.
- [ ] Собрать минимальный эксперимент: исходный текст → локальный этап → fallback на выбранный агент.
- [ ] Проверить вложенное делегирование с одним conversation ID: дубли пользовательских сообщений, блокировки, ошибки, ответ и trace.
- [ ] Проверить передачу `context`, языка, conversation ID, device/satellite ID и extra system prompt, если они поддерживаются целевой версией.
- [ ] Проверить продолжение диалога LLM: следующий ответ пользователя не должен ошибочно перехватываться локальной обработкой. Определить хранение состояния маршрута по conversation ID и его очистку.
- [ ] Проверить возможность сохранения streaming LLM через обёртку; зафиксировать ограничения MVP.
- [ ] Подтвердить поведение ранних sentence triggers при выключенном внешнем чекбоксе.

## Критерии готовности

- Локальная команда обрабатывается без обращения к LLM.
- Запрос без локального результата получает ответ от llamacpp.
- Проверены минимум две последовательные реплики в одном диалоге и два независимых разговора.
- Выполнение локальной команды не дублируется при делегировании.
- В `docs/architecture.md` записаны проверенные API, политика fallback, поведение истории и follow-up, ограничения streaming и ссылки на исходники целевых версий.
- Непроверенные предположения явно отделены от результатов эксперимента; блокирующие проблемы отражены в следующих задачах.
