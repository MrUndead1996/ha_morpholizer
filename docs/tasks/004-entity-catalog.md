## Работа

- [ ] Создать `catalog.py` с записями: entity ID, реальные имена/aliases, домен и доступный контекст комнаты.
- [ ] Получать имена из состояний и registry согласованно с поведением штатного агента целевой версии HA.
- [ ] Индексировать только сущности, доступные Assist; каталог не должен расширять exposure.
- [ ] Сохранять неоднозначные имена как несколько кандидатов, не выбирать первую сущность произвольно.
- [ ] Обновлять индекс при добавлении, удалении, переименовании, изменении aliases и exposure, а также изменении имени из состояния.
- [ ] Объединять серии обновлений и заменять снимок индекса целиком, чтобы запрос не видел частично обновлённые данные.
- [ ] Удалять подписки при unload.

## Критерии готовности

- Переименование и изменение aliases учитываются без перезапуска HA.
- После отключения exposure сущность исчезает из кандидатов.
- Одинаковые имена разных сущностей сохраняют неоднозначность.
- Проверены сущности без registry entry, отсутствующее состояние и удаление сущности; политика для unavailable документирована.
- Изменение обычного состояния без изменения имени не вызывает дорогостоящую полную перестройку словаря.
