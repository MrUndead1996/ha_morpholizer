# План разработки Morpholizer

## Цель и целевое окружение

- Home Assistant Core: **2026.11.1**.
- Fallback: существующий **llamacpp conversation agent** пользователя.
- Формат: custom integration с доменом `morpholizer` и conversation entity.
- В Assist выбран Morpholizer; штатная опция «Предпочитать локальную обработку команд» выключена.
- Morpholizer нормализует названия, пробует локальную обработку HA и при отсутствии локального результата передаёт запрос выбранному LLM-агенту.

```text
STT / текст → Morpholizer → нормализация → локальные intents
                                             ├→ результат → ответ
                                             └→ нет результата → llamacpp → ответ
```

## Границы MVP

- Русский язык; имена и aliases сущностей, доступных Assist.
- Нормализация только упоминаний сущностей; остальной текст сохраняется.
- LLM получает нормализованный текст; если уверенной замены нет — исходный.
- Ошибка выполнения распознанной локальной команды сама по себе не запускает LLM fallback.
- Ранние sentence triggers Assist могут сработать до Morpholizer. Глобальный перехват и monkey patch не входят в MVP.
- Комнаты и этажи как самостоятельные объекты нормализации — следующий этап.

## Основания и открытые вопросы

Предварительное R&D выполнено по ветке разработки HA. При создании каркаса дополнительно проверены исходники conversation API и требования Python тега **2026.11.1**. Полная runtime-совместимость маршрутизатора с локальными интентами и пользовательским LLM ещё не подтверждена; это обязательная часть задачи 001. Подробности — в [архитектуре](../architecture.md).

Точное название репозитория и версия llamacpp-интеграции пока неизвестны. В задаче 001 нужно зафиксировать их вместе с entity ID целевого агента, не предполагая конкретную реализацию по одному названию.
