## Критерии готовности

- Интеграция добавляется и удаляется через UI HA 2026.11.1.
- Morpholizer доступен в списке агентов Assist, llamacpp выбирается как fallback.
- Некорректная конфигурация не приводит к рекурсии.
- Reload не создаёт дубликаты сущностей и не оставляет подписок.
- Есть значимые проверки config flow, выбора fallback и жизненного цикла интеграции.

## Текущий объём

Каркас вынесен вперёд полного routing spike по запросу пользователя. Он делегирует неизменённый текст выбранному агенту; локальный этап и нормализация отсутствуют. Наличие каркаса не закрывает задачу 001 и не доказывает совместимость с конкретной llamacpp-интеграцией.

Добавлены проверки setup/unload/listener, параметров делегирования, недоступного и собственного fallback, `unknown` состояния и двух реплик через настоящий dispatcher HA с тестовым агентом. Runtime-зависимости морфологии пока намеренно не добавлены. Ручная установка и изменение настроек через UI пользовательского HA ещё не проверены.
