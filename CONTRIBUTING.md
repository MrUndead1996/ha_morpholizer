# Разработка

Начните с [README](README.md#разработка): там описаны архитектура, ограничения и оставшиеся проверки перед релизом.

## Проверки перед изменениями

```sh
uv sync --locked
uv run ruff check .
uv run ruff format --check .
uv run pytest
```

Лёгкие проверки не загружают Home Assistant. Для дополнительных smoke-тестов с реальными классами **HA 2026.11.1**:

```sh
uv sync --locked --group integration
uv run --group integration pytest -q
```

Внешний агент и отдельные интерфейсы HA в этих тестах подменяются. Изменения conversation API, config flow и жизненного цикла нужно дополнительно проверять в запущенном HA. Для изменений маршрутизации проверяйте отсутствие повторных действий и утечки контекста между разговорами, а не только количество внутренних вызовов.

## Правила архитектуры

- Runtime-файлы находятся в `custom_components/morpholizer/`.
- Сторонние runtime-зависимости объявляются в `manifest.json`; HA устанавливает их самостоятельно.
- Не добавляйте зависимости морфологии до проверки их совместимости с целевым Python и HA.
- Не используйте monkey patch штатного pipeline.
- Не логируйте запросы и названия пользовательских сущностей на обычном уровне логирования.
- Не объявляйте поддержку streaming и управления домом до проверки соответствующих контрактов.
- Фиксируйте подтверждённые результаты и ограничения в README; не отмечайте сквозные сценарии выполненными на основании одних mock-тестов.

Проект пока не имеет выбранной лицензии. Перед публичным релизом владелец репозитория должен определить условия распространения.
